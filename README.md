# Smart Personal Expense Tracker & Spending Analytics System

## 📌 Project Overview

The **Smart Personal Expense Tracker & Spending Analytics System** is a Python-based data analytics project designed to help users record, manage, analyze, and understand their personal spending.

The project combines expense management with data analysis, visualization, budgeting, and automated spending insights.

---

## 🎯 Objectives

- Record and manage personal expenses
- Store expense data using CSV files
- Maintain persistent data using Google Drive
- Analyze spending using Pandas
- Perform category-wise and monthly analysis
- Track monthly budgets
- Generate smart spending insights
- Identify data-quality issues
- Create analytical dashboards
- Export reports to Excel

---

## ⚙️ Key Features

### Expense Management
- Add new expenses
- View all expenses
- Delete incorrect expenses
- Search and filter expenses
- Validate user inputs

### Data Analysis
- Expense summary reports
- Category-wise spending analysis
- Monthly spending analysis
- Average and total spending calculations
- Highest and lowest expense identification

### Budget Management
- Monthly budget tracking
- Budget utilization percentage
- Remaining budget calculation
- Budget warning and exceeded status
- Spending recommendations

### Data Visualization
- Category spending bar chart
- Spending distribution pie chart
- Monthly spending trend
- Expense distribution box plot
- Outlier analysis

### Smart Insights
The system generates spending insights based on:
- Highest spending category
- Spending percentage
- Average expense
- Monthly spending patterns
- Budget utilization

### Reporting
- Excel analytical report
- Summary sheet
- Category Analysis sheet
- Monthly Analysis sheet
- All Transactions sheet
